# 🏦 Bankist — Modern Digital Banking Website

A modern, minimalist banking website built with **HTML, CSS, and Vanilla JavaScript**, featuring interactive UI components, smooth animations, and responsive layouts.

Bankist focuses on delivering a clean and engaging user experience through elegant design, dynamic interactions, and efficient DOM manipulation.

### 🌐 Live Demo

**[🚀 Explore Bankist Live](https://elyardev.github.io/Bankist/)**

## ✨ Features

- **Responsive Design** — Adaptable layouts for different screen sizes.
- **Interactive Navigation** — Smooth scrolling between page sections.
- **Sticky Navigation Bar** — Keeps navigation accessible while scrolling.
- **Tabbed Operations** — Switch between instant transfers, loans, and account closing.
- **Testimonial Slider** — Interactive carousel with navigation buttons, pagination dots, and keyboard controls.
- **Modal Window** — Interactive account-opening modal with overlay and keyboard dismissal.
- **Scroll Reveal Animations** — Sections appear as they enter the viewport.
- **Lazy Loading Images** — Images load as users approach them while scrolling.
- **Navigation Hover Effects** — Subtle opacity transitions for a polished interface.
- **Cookie Notification** — Dismissible notification message.
- **Smooth User Interactions** — Engaging transitions and intuitive interface behavior.

## 🛠️ Built With

- **HTML5** — Semantic page structure.
- **CSS4** — Styling, layouts, and visual effects.
- **JavaScript (ES6+)** — Interactive components and DOM manipulation.
- **Intersection Observer API** — Scroll-triggered animations, sticky navigation, and lazy loading.
- **Google Fonts** — Poppins typography.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/ElyarDev/Bankist.git
```

### 2. Navigate to the project directory

```bash
cd Bankist
```

### 3. Run the project

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

No additional dependencies or build tools are required.
